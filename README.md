# Книжная полка — Android (APK)

Мобильное приложение с собственным интерфейсом для поиска книг по OPDS-каталогу, просмотра карточек, избранного, загрузок и чтения поддерживаемых форматов. Основной источник в настройках: `https://http.flibusta.is`.

**Статус:** исходники проверены статически. В этой среде не было Android SDK и интернета для его загрузки — поэтому исполняемый APK **ещё не собран**. Наличие приложения в Google Play не предполагается.

## Самый простой путь: получить APK через GitHub без Android Studio

1. Войдите на https://github.com/ под своей учётной записью.
2. Нажмите **New repository**. Назовите репозиторий `knizhnaya-polka-android` (рекомендуется **Private**, если не хотите публиковать исходный код) и нажмите **Create repository**.
3. Распакуйте архив `Книжная_полка_APK_СБОРКА.zip` на компьютере. Важно: **все файлы из архива должны оказаться в корне репозитория**, в том числе скрытая папка `.github/workflows` и её файл `build-apk.yml`. Не загружайте сам ZIP вместо файлов. Чтобы надёжно сохранить вложенные папки, используйте GitHub Desktop (см. ниже) либо загрузку папок через веб-интерфейс GitHub при поддержке браузером.
4. В GitHub откройте вкладку **Actions**. Если GitHub предложит разрешить выполнение workflows, разрешите для этого репозитория.
5. Откройте **Собрать APK «Книжная полка»** и нажмите **Run workflow → Run workflow**. При `push` в ветку `main` сборка может начаться автоматически.
6. После успешного выполнения (зелёная отметка) откройте запуск. Внизу, в разделе **Artifacts**, скачайте **Knizhnaya-Polka-install-APK**. Это ZIP, **внутри которого находится `app-debug.apk`**.
7. Распакуйте ZIP, передайте `app-debug.apk` на телефон и откройте его. Android может попросить включить разрешение на установку приложений из этого источника. Разрешайте только если доверяете собранному вами файлу.

> Важно: GitHub Actions *соберёт* APK только после загрузки файлов и успешного запуска. До этого готового APK у вас нет. Документация GitHub: https://docs.github.com/en/actions/how-tos/manage-workflow-runs/download-workflow-artifacts

### Более надёжная загрузка проекта через GitHub Desktop

1. Установите GitHub Desktop: https://desktop.github.com/ .
2. Создайте новый локальный репозиторий в GitHub Desktop.
3. Перенесите **содержимое** распакованного ZIP в созданную папку проекта (рядом с `.git`), в том числе каталог `.github`.
4. В GitHub Desktop нажмите **Commit to main → Publish repository**.
5. Вернитесь в GitHub → **Actions** и скачайте APK из результатов сборки.

## Альтернатива: Android Studio

1. Откройте папку проекта в Android Studio.
2. Установите Android SDK Platform 35, Build Tools 35.0.0, JDK 17.
3. Нажмите **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
4. Найдите готовый файл в `app/build/outputs/apk/debug/app-debug.apk`.

## Проверка и ограничения

- Рассчитано на Android 10+ (minSdk 29).
- Установленная APK-версия не требует включённого компьютера: она подключается непосредственно к OPDS из Android-кода.
- Для поиска и скачивания нужен интернет и доступность указанного OPDS-сервера.
- В этой среде невозможно было подтвердить живой доступ к `https://http.flibusta.is/opds`; если источник не отвечает, приложение покажет ошибку.
- Для несовместимых форматов может потребоваться установленная на телефоне читалка.
- Сохранение книг в `Загрузки/Книжная полка`, ограничение размера файла 70 МБ.
- Отладочный APK подписан техническим **debug-ключом** Android Gradle; он годится для личной установки, но не для публикации в магазине.
- Используйте только те книги, которые разрешено скачивать и распространять согласно применимым правилам.

Это учебно-прикладной OPDS-клиент, не обходящий DRM, блокировки или требования правообладателей.
