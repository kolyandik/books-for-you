КНИЖНАЯ ПОЛКА — APK ДЛЯ ANDROID

В этом ZIP находится готовый Android-проект для компиляции, А НЕ УСТАНОВОЧНЫЙ APK.

Самый лёгкий путь без Android Studio:
1. Распакуйте ZIP.
2. Загрузите все файлы и папки в корень нового репозитория GitHub, включая .github/workflows.
3. Откройте GitHub → Actions → «Собрать APK «Книжная полка»» → Run workflow.
4. После зелёного статуса скачайте Artifacts → Knizhnaya-Polka-install-APK.
5. Распакуйте скачанный ZIP и установите app-debug.apk на Android.
